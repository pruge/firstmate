# T05 — T-review: 사관장 검수

## Goal
feature 완성 상태를 사관장과 함께 승인된 수용기준대로 검수한다.

## Why this slice
피드백 루프를 feature 말단에 내장하는 D7 계약의 실제 수행. 경미/중대 분류로 재작업 번짐을 방지한다.

## Scope
- firstmate가 변경 요약과 함께 검수 표면 제공(파일 목록, 스킬별 핵심 계약, PR 링크)
- 사관장이 수용기준(spec.md)대로 검수
- 경미 피드백: 동일 워커가 수정 커밋 + 관련 문서(grill/spec/tickets)를 실체에 맞게 갱신
- 중대 피드백: 새 작업 항목으로 기록 후 재귀 진입(task-planning 재실행)

## Implementation notes
- 검수 통과 후 착륙은 기존 merge authority 절차 따른다(사관장 승인).

## Acceptance criteria
- 사관장 검수 완료 판정 또는 중대 피드백의 새 작업 항목 등록

## Verification
사관장 응답 기록(hold answer 또는 chat 확인)

## Depends on
- T04

## Can run in parallel with
- nothing
