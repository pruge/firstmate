# T03 — task-planning 오케스트레이터 개편

## Goal
기존 SKILL.md를 패밀리 오케스트레이터로 개편하고 원본 기법을 이식한다.

## Why this slice
패밀리의 진입점이자 기존 자산의 흡수처. T01·T02의 계약을 참조·조율한다.

## Scope
- fog-of-war 이식: Not-yet-specified 섹션 + "지금 정확히 질문화 가능한가" 판정선 + 졸업 절차
- map-as-index: wayfinder.md는 색인, 결정 본체는 단일 출처
- 티켓 유형 매핑 명문화: research=--scout(AFK) / prototype=task-design(HITL) / grilling=task-grill·hold(HITL) / task=사관장 체크리스트 또는 crew
- seam 우선 기법(to-spec): 최소·최상위·기존 선호 + spec 작성 전 사관장 확인 절차
- spec 템플릿 강화: user stories 확장 리스트, 파일경로·코드 금지(프로토타입 스니펫 예외)
- 티켓 퀴즈 루프(to-tickets): 세밀도/엣지/병합분할 반복 조정 후 확정
- expand-contract 패턴(광역 리팩터링 예외)
- 재귀 게이트(D6): dispatch 직전 복잡도 재판정 → 티켓=새 부모 진입, 크기 상한(티켓당 컨텍스트 윈도우 1개)
- T-review 의무(D7): 그래프 말단 검수 티켓 + 경미/중대 분류 규칙 + 품질 게이트 검사항목 추가
- T01·T02와 중복되는 내용은 제거하고 한 줄 참조로 대체(one-owner rule)

## Implementation notes
- 기존 유지 항목 명시 보존: 복잡도 게이트, 품질 게이트, 승인 게이트, 위험도별 검증, brief/spawn 인계, <parent>-t<NN> 식별자.

## Acceptance criteria
- 이식 항목 10건이 모두 문서에 존재한다
- T01/T02와의 중복 서술이 없다(참조만)
- 기존 유지 항목이 손상되지 않았다

## Verification
원본 대조표(grill.md D1~D7) 충족 확인 + diff 리뷰
