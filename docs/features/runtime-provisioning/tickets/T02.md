# T02 — dev DB·env 복사 + kill-port 이식

## Goal
작업 사본이 실행 가능한 개발 환경(DB·env)을 갖고 시작하며, crew가 안전하게 자기 포트를 정리할 수 있게 한다.

## Why this slice
tracked-only 체크아웃으로 인한 "실행할 것이 없다" 문제와 이름 패턴 종료의 위험을 함께 닫는 두 번째 조각.

## Scope
- bin/fm-worktree-bootstrap.sh 이식·적응(사관장 작업 사본 → 워크트리 untracked 개발환경)
- bin/fm-kill-port.sh 이식(포트 기반 종료 + 트리 경계 거부 규칙)
- tests/fm-kill-port.test.sh 이식 + bootstrap 해당 테스트

## Implementation notes
- 복사는 best-effort: 없는 소스는 조용히 생략, 복사 실패는 경고(spawn 실패 아님) - 구현 주석 계약 유지.
- kill-port 경계 규칙과 --any 플래그 의미 보존.

## Acceptance criteria
spec 2·4·5·6번.

## Verification
이식 테스트 green + fm-lint + diff 리뷰.

## Depends on
- T01 (같은 spec 안에서 런타임 프로비저닕 흐름 완성)

## Can run in parallel with
- nothing
